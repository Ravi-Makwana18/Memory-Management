# 🧠 MemoryCraft

**MemoryCraft** is an interactive web application designed to help users understand memory allocation algorithms used in operating systems. It provides a clean and simple UI to **learn** theoretical concepts and **visualize** how memory allocation works in both **Fixed Partitioning** and **Dynamic Partitioning** strategies.

---

## 🚀 Features

- 📚 **Learn Section**: 
  - Understand core memory allocation concepts like Fixed and Dynamic Partitioning.
  - Covers variations like First Fit, Next Fit, Worst Fit, and Best Fit with clear explanations.

- 🧩 **Visualise Section**
  - Step-by-step visual representation of how processes are allocated memory.
  - Observe internal and external fragmentation.

- ⚙️ Built with:
  - React.js + Vite
  - Tailwind CSS
  - Component-based modular structure
